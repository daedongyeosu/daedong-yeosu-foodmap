# 대동여수음식지도 광고 배너 2.0

## 교체 방법
1. GitHub Desktop에서 `Show in Explorer`를 누릅니다.
2. 저장소 안의 기존 `index.html`과 `images` 폴더를 백업합니다.
3. 이 패키지의 `index.html`과 `images` 폴더를 저장소에 덮어씁니다.
4. GitHub Desktop에서 Summary에 `모바일 광고 배너 2.0 적용` 입력
5. `Commit to main` → `Push origin`
6. GitHub Pages 배포 완료 후 기존 주소를 새로고침합니다.

## 적용 내용
- PNG 17장 → WebP 변환
- 모바일 900×525 및 원본 1200×700 반응형 제공
- 첫 광고 우선 로딩
- 다음 2개 광고 사전 로딩
- 나머지 광고 지연 로딩
- 로딩 표시
- 모바일 스와이프
- 노션 임베드가 높게 잡혀도 흰 여백 대신 광고 이미지 기반 흐림 배경 표시

참고: 노션 모바일의 `원본 보기` 표시는 노션 앱 자체 UI이므로 웹페이지 코드에서 제거할 수 없습니다.
